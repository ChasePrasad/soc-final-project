==============================================================================================================================================
                                                                 SETUP (NO SD)
==============================================================================================================================================
1. Setup the Environment
Run "source settings.sh" inside your PetaLinux installation folder [likely within Petalinux_SoftData] so your terminal understands the tools


2. Navigate to the Workspace
Run "cd ~/Petalinux_HardData"

3. Create the Base Project
Run "petalinux-create --type project --template microblaze --name image_filter_os"

4. Import the Hardware Architecture
Run the following:
cd image_filter_os
petalinux-config --get-hw-description={path/to/hardware_spec.xsa}

5. Disable U-Boot Networking
Run "petalinux-config -c u-boot" and then go to "Networking" => "Networking Stack" and select "No networking support", then save and exit.

6. Configure Root Filesystem
Run "petalinux-config -c rootfs" and then go to "Filesystem Packages" => "devel" => "python3" => "python3" => "python3" and activate by
pressing 'Y', then save and exit

7. Build the OS
Run "petalinux-build"

==============================================================================================================================================
                                                                TESTING (NO SD)
==============================================================================================================================================
1. Connect to the Board's Serial Port
Open a brand new terminal window while keeping your Petalinux window open in the background and run "sudo minicom -D /dev/ttyUSB1 -b 115200"

2. Push the OS (JTAG)
Go back to the original Petalinux terminal window, plug in your board, and run "petalinux-boot --jtag --fpga --kernel"

3. Log into PetaLinux
Once the boot sequence finishes in your minicom window, log in:
- Username: petalinux
- Password: (It will immediately prompt you to create a new password. Type something simple like 'root')

4. Create the DMA Test Script
Create a new Python file directly on the board using the vi text editor by running "vi test.py". Then, copy and paste
(may have to use ctrl + shift + v instead of just ctrl + v) the test_dma.py file from our repo to the new file you just made.
Finally, press 'Esc', type ":wq", and press 'Enter' to save and exit the text editor (TRUST ME)

5. Run the Test
Run "sudo python3 test.py". If all goes well, all the tests should pass

==============================================================================================================================================
                                                                SETUP (WITH SD)
==============================================================================================================================================
1. Pre-SD-Setup
Follow steps 1-6 from SETUP (NO SD)

2. SD Configuration Pt. 1
Run "petalinux-config" then go to "Subsystem Hardware Settings" => "Flash Settings" => "Primary Flash (...) " and
change it to "perifs_axi_perifs_axi_quad_spi_0". Once back in the main menu, also go to "Image Packaging Configuration" =>
"Root filesystem type (...)" and select "EXT4 (SD/eMMC/SATA/USB)"

3. SD Configuration Pt. 2
Run "petalinux-config -c kernel" then go to "Device Drivers" => "MMC/SD/SDIO card Support" (Press 'Y' and then 'Enter') =>
Press 'Y' for the following: "HW reset support for eMMC", "Simple HW reset support for MMC", "MMC block device driver",
"SDIO UART/GPS class support", and "MMC/SD/SDIO over SPI" (Please make sure its a '*' and not an 'M')

4. SD Configuration Pt. 3
Run "nano project-spec/meta-user/recipes-bsp/device-tree/files/system-user.dtsi" and ensure that it contains the following:
/include/ "system-conf.dtsi"
/ {
    aliases {
        spi0 = &perifs_axi_perifs_axi_quad_spi_0;
    };
};

&perifs_axi_perifs_axi_quad_spi_0 {
    status = "okay";
    num-cs = <1>;
    #address-cells = <1>;
    #size-cells = <0>;

    /* Kill the auto-generated ghost flash node */
    /delete-node/ flash@0;

    sdcard@0 {
        compatible = "mmc-spi-slot";
        reg = <0>;
        spi-max-frequency = <400000>; /* Safe Mode for weak pull-ups */
        voltage-ranges = <3300 3300>;

        /* The 1-Bit Shift Fix (Clock Polarity/Phase) */
        spi-cpol; 
        spi-cpha; 

        broken-cd;
        disable-wp;
        bus-width = <1>;
    };
};

5. SD Configuration Pt. 4
Run "cd project-spec/meta-user/recipes-bsp" and then "mkdir fsboot". cd into the newly created folder, run "nano fs-boot.bbappend", and paste:
do_compile:prepend() {
    find ${WORKDIR} -name "*.c" -exec sed -i 's/CONFIG_FS_BOOT_START/0x0/g' {} +
    find ${WORKDIR} -name "fs-xspi.c" -exec sed -i '1i #define XSP_BASEADDR 0x44A20000' {} +
}
into the newly created file, then save and exit

6. Build the OS
Run "petalinux-build"

7. Compile the Executable
Bring the source files to your linux environment. Run "petalinux-build --sdk" and then "petalinux-package --sysroot". After the second command
you should get an output that ends with a very long filepath,
like "/home/donut/Petalinux_HardData/image_filter_os/images/linux/sdk/environment-setup-microblazeel-v11.0-bs-cmp-re-fo-mh-div-fe-amd-linux".
Run "source [your long filepath]" and then "$CC -O2 -o image_filter image_filter.c -lm"

8. Mount the SD Card's BOOT Partition
Once you have the SD card connected to your laptop, run "lsblk" and note the name of the SD card and its partitions
(usually "sda" if using a USB adapter or "mmcblk0" if reading directly). Run "sudo mkdir /mnt/sdcard" and then
"sudo mount /dev/[SD card BOOT PARTITION name (the smaller and usually first one)]"

9. Update the BOOT Partition
Run "sudo cp images/linux/boot.scr /mnt/sdcard" and "sudo cp images/linux/image.ub /mnt/sdcard". Then run "sync" and "sudo umount /mnt/sdcard"

10. Mount the SD Card's rootfs Partition
Run "sudo mount /dev/[SD card rootfs PARTITION name (the larger and usually second one from step 8)]"

11. Update the rootfs Partition
Run "sudo rm -fr /mnt/sdcard/*" and "sudo tar -xzf images/linux/rootfs.tar.gz -C /mnt/sdcard"

12. Set up SD Card for Use
Ensure that the SD Card has, at the minimum, the compiled "image_filter" executable from step 7 and the images you want to use the filters on
placed into "/mnt/sdcard/home/petalinux/". Then run "sync" and "sudo umount /mnt/sdcard" and placed the SD card into the board's SD card slot

==============================================================================================================================================
                                                                USAGE (WITH SD)
==============================================================================================================================================
1. Connect to the Board's Serial Port
Open a brand new terminal window while keeping your Petalinux window open in the background and run "sudo minicom -D /dev/ttyUSB1 -b 115200"

2. Push the OS (JTAG)
Go back to the original Petalinux terminal window, plug in your board, and run "petalinux-boot --jtag --fpga --kernel"

3. Enter the Boot Process
When you see "Hit any key to stop autoboot", press 'Enter' immediately to drop into the U-Boot menu. You only need to press it once and wait

4. Mount the SD Card and Boot
Run 'setenv bootargs "console=ttyUL0,115200 earlycon earlyprintk root=/dev/mmcblk0p2 rw rootwait mem=64M"' and then
"bootm 0x80000000 - 0x81e00000". Make sure the USB_C port is plugged in for the EXTPWR

5. Log into PetaLinux
Once the boot sequence finishes in your minicom window, log in:
- Username: petalinux
- Password: (It will immediately prompt you to create a new password if this is a new instance. Type something simple like 'root')

6. Run the Test
Find the executable on the SD card and run "sudo ./image_filter [input.png] [filter_mode] [output.png]". If you get a "permission denied"
error, run "sudo chmod +x image_filter". If all goes well, the output image should be placed in the specified filepath
